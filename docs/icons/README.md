# Service logos

The README uses locally packaged brand SVGs from
[Simple Icons 13.0.0](https://github.com/simple-icons/simple-icons/tree/13.0.0/icons),
distributed under [CC0 1.0](https://github.com/simple-icons/simple-icons/blob/13.0.0/LICENSE.md).
Paths are unchanged; fill colours use that release's brand metadata.

SVGs declare an intrinsic 24 × 24 pixel size. Use Markdown image syntax in the
README: the Signal K Store renderer displays raw HTML image tags as text.

| Asset           | Brand source                          | Colour    |
| --------------- | ------------------------------------- | --------- |
| `ntfy.svg`      | https://ntfy.sh                       | `#317F6F` |
| `pagerduty.svg` | https://www.pagerduty.com/brand/      | `#06AC38` |
| `discord.svg`   | https://discord.com/branding          | `#5865F2` |
| `telegram.svg`  | https://telegram.org/tour/screenshots | `#26A5E4` |

These logos identify supported integrations, not endorsement. Brand names and
trademarks remain the property of their owners. The Signal K Wyoming row is
text-only because its upstream repository provides no dedicated logo asset.
